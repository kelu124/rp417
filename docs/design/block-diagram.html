Rail order (DS V1.9 §1.4.3, Table 3-2): VDD33 ≥ VDD33A ≥ VDDIO ≥ VIO18 — met by one 3V3 rail (D23, D25). Internal LDO load (DS V1.9 Tables 3-6-4/3-6-5): IDDK ≈ 112 mA at 400/100 MHz all peripherals + IDD12A ≈ 85 mA with USB3 → ≈ 0.2 A × (3.3 − 1.2) V ≈ 0.4 W in the LDO, ≈ 0.75 W for the whole chip. No θJA in the datasheet; with a typical 25–35 °C/W for a QFN128 with its pad stitched into 6 layers → +20–25 °C, well inside TJ ≤ 105 °C (estimate, to measure).

  • No switch chip (D36): each CH32 pin has its own AF0–AF15 mux, and a pin left in plain input mode is not connected to any alternate-function input (RM V1.8 §9.2). Firmware sets AF13/AF11 only on the active set.
  • Counter is 8-bit (D8/D9 have no free alternate — PC10/PC12 are SDMMC); capture runs in 10-bit mode, so 16-bit words and the same 130 MB/s at 65 MS/s. Host checks the low 8 bits.
  • DVP in JPEG mode: HSYNC may be held static, buffer switching follows the DMA length (RM V1.8 §29.2.2, §29.3.1) → RP sync needs no alignment to PCLK (D37). Gapless streaming still to prove on hardware.
  • RP2350 PIO: one sample per two instructions → ~75 MS/s at 150 MHz system clock, more if overclocked. Series R on these lines ≈ 33–47 Ω (source termination).
  • ADC10065 fitted by hand (DNP, D42). With it absent the primary pins float harmlessly (configured as inputs).
  • UHSIF not routed (D21).

  • Doubly-terminated filter: fundamental ≈ (4/π)·(3.3/2)·½ ≈ 1 V peak ⇒ ≈ 2 Vpp ideal; the Si5351 driver impedance lowers it (estimate 1.5–2 Vpp, bench-verify). Clean sine from ≈ 10 to 30 MHz; below fc/3 a shaped square.
  • ADC10065 single-ended full scale = 2.0 / 1.5 / 1.0 Vpp for IRS = VDDA / VSSA / floating (ADC10065.md) — see P3-1.
  • CH32 ADCs get the same net with no anti-alias filter: 10–30 MHz aliases at 5/20 MSPS (deterministic, fine for throughput, D35).

No bus switches (D29): the RP2350 is always powered, so the only back-feed direction is RP → CH32. Power-off sequence in RP firmware: tri-state GPIO0–20 and 31–36, disable Si5351 CLK0–2, assert NRST, then drop PWR_EN; check GPIO40 reads ≈ 0 V. Series resistors only limit clamp current if firmware misbehaves.
