CH32 rail order (datasheet V1.9 §1.4.3, Table 3-2): VDD33 ≥ VDD33A ≥ VDDIO ≥ VIO18, VDD33A ≥ VREFP, and with HSADC VDDIO ≥ VREFP. VDDK/VDD12A 1.17–1.27 V. A shared enable plus active output discharge on all CH32-domain regulators so the domain really returns to 0 V when off (verified by the RP2350 ADC, D08).

  RPS["RP2350 HSYNC / VSYNC

  • ADC10065 has no clock output and no output enable (only STBY) — hence a separate phase-tunable Si5351 output for the CH32 capture edge, and the 2:1 switch for counter-pattern injection (D16).
  • RP2350 PIO: one sample per two instructions → ~75 MS/s at 150 MHz system clock, higher if overclocked. Target ≥ 65 MS/s.
  • DVP stores 10-bit samples as 16-bit words: 65 MS/s ⇒ 130 MB/s into SRAM, streamed out over USB3.
  • UHSIF is not routed in P1 (its pins overlap SDMMC/ADC). Possible later revision.

5. RP2354B pin plan (48 GPIO)

The RP2350A has 30 GPIO, which is too few; the B variant (QFN80) is needed. RP2354B = RP2350B with 2 MB flash in the package (saves a flash chip on a playing-card board). All 48 GPIO are used.
